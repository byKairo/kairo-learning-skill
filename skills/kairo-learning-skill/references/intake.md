# 首次问诊与路线

首次启动只问尚缺的信息，默认合并为三问：

1. 你想学什么，准备在哪个具体场景使用？希望最后能独立完成什么？如果说不清，给出该领域 2～3 个具体成果例子帮助选择。
2. 你已经学过、做过什么？最近卡在哪一步？没有基础也可以直接说没有。
3. 每周能投入多少时间，通常一次多久？有没有希望完成的日期？

答案到达后再补充确有必要的材料、设备、语言或考核约束，不一次问齐所有偏好，不按所谓视觉型或听觉型学习者分配教学。

诊断不能重复自评。选一个直接关系目标的短任务：解释一个关键概念、判断两个案例、完成一个最小操作等。明确允许说不知道。缺少前置知识时提供必要教学，再设置新题；不要将教学后的作答反推为原有能力。

能力目标使用可观察动词：辨认、解释、独立操作、比较并说明依据、在新条件下解决问题。每个目标列出必要标准及允许工具，避免用“全面掌握”“精通”验收。用户要广泛探索时，可先设一个短期探索阶段，完成条件是形成领域地图并选定下一目标。

路线通常列出 3～5 个阶段，每阶段写成果、前置依赖和检验任务。少量目标无需凑数。教学节数与日期是可调整估计，不承诺固定天数学会。多个领域分别建档，只有排期需要时协调总预算，不把单一领域表现迁移为其他领域已掌握。

先展示目标契约和近期路线供用户纠正；没有必须等待的关键缺口时可直接开始诊断或第一节，不反复要求批准。
