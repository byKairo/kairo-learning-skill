# 学习档案

## 内容取舍

保存支持续学的最少信息，不保存完整聊天、重复讲解、搜索结果清单或未采用材料。当前摘要原位更新；会话历史只保留改变目标、能力判断、误区或下一步的必要证据。重复来源和同一误区合并，已解决误区移入简短历史并保留修正证据，不继续列为当前问题。重要作品单独保存并链接，不反复复制进摘要。不自动删除原始作品或有价值的历史证据。

探索问答记录已讨论概念及关系、明确误区和最后探索位置，不能把已讨论写成已掌握。不为每个简短问答增加一份会话文件；有续学价值的变化才更新。

学习库必须跨对话稳定。优先使用用户指定位置；未指定时默认使用用户文档目录下的 Codex/learning-records，按环境解析实际文档路径，不写死用户名。可写时直接初始化并告知位置；不可用时询问一次固定位置，不静默改用每次变化的当前工作区。默认不扫描私人目录、不写入 Skill 安装目录、不自动跨设备同步。

用户选用其他位置时，在默认位置可写的情况下保存 location.json，格式为 {"root":"学习库绝对路径"}。新对话先检查本次显式路径，其次默认位置的 location.json，最后默认学习库。读取 root 并核实目标目录存在；配置损坏或目标不可达时报告并请求修正，不能静默另建学习库。默认入口不可写时提供含真实路径的续学调用句，说明新对话须带该路径。移动档案同步更新入口。

目录包含 index.md，登记领域名称、档案相对路径、最近活动和下一步；领域内 record.md 保存摘要，sessions/ 保存会话，sources.md 保存备课来源及支持结论。按 assets 模板记录实际信息，未知项写未提供或未检验，不虚构成绩。文件名使用安全短名，拒绝路径穿越字符。

写入步骤：先读取现有记录；合并新证据并保留历史；同日多次记录使用时间或递增后缀避免覆盖；更新当前摘要和索引；读回核实。若发现其他会话改动，重新读取合并，不覆盖较新的证据。写入失败时准确报告，并在对话提供最小续学记录。

记录应包括题目、用户实际答案的必要摘要、判定理由、提示程度、日期和下一次任务。区分自述、实际作答、外部作品三种证据来源；保存学习所需的最少个人信息，不复制无关聊天。

每次调用都先检查固定入口，读取索引、指定领域摘要和必要最近记录，再简短说明上次位置。只有一个活跃领域可直接恢复；多个且意图不明时只问继续哪个。用户要新领域就新建，保留原档案。文件不可达时请求原位置或续学摘要，不假装记得。跨对话恢复依赖能访问同一学习库，不能承诺跨设备或无文件环境自动恢复。

每次出题、收到回答、改变路线或跳过后立即更新，不等结束口令。待答题恢复时可问“上次这道题还没回答，你想先回答，还是跳过继续？”已明确跳过则不重复确认。跳过不计掌握，开放任务保留分析而非强制通过状态。隔时检验需要真实后续作答，计划日期不是证据。写入失败时说明未保存并给续学摘要。
