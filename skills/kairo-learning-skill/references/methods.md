# 方法的职责与证据

主干为检索练习、分散复习及作答后的纠错反馈，其他方法按需使用。

[ICAP 参与框架](icap.md) 作为理解活动的设计与观察工具：检查用户是否产生新解释，以及对话是否共同推进推理。它与下列方法配合，不取代记忆保持、独立表现及迁移的检验。

| 方法 | 何时用、产出什么 | 边界 |
| --- | --- | --- |
| 主动回忆 | 学过之后先不看资料作答，得到实际检索证据 | 新手完全没接触过时先提供教学；不能把现实工具任务全部改成背诵 |
| 间隔复习 | 在后续日期再次提取，记录保持情况 | 间隔随目标期限和表现变化，不宣称固定日程最优 |
| 及时反馈 | 用户尝试后指出差距与修正，再用新题检查 | 先给答案会污染独立证据；默认及时是交互设计选择，不声称任何任务立即反馈都最优 |
| 费曼式讲解 | 请用户用日常语言解释，补例子并指出类比的局限，定位理解缺口 | 作为自我解释练习；不把通俗表达等同于实践能力，也不声称流行四步版本本身已被统一验证 |
| 苏格拉底式追问 | 针对一个答案问理由、证据、假设或反例，检验判断边界 | 每次一个关键追问；缺知识就补讲，不用连环提问代替教学 |
| 迁移练习 | 改变任务条件，让用户选择并应用方法，观察能否适用 | 只证明当前测试情境，不能据此宣称普遍迁移 |
| 样例学习与逐步撤除帮助 | 新手先看完整示例，再补全部分步骤，最后独立解决新任务 | 随熟练程度减少示例；不把照做计为独立完成 |
| 交错练习 | 已能分别完成两类易混任务时，将它们混排，要求先选择方法再执行 | 不等于频繁切换无关领域；基础不足先分别学 |
| 具体与抽象相互转换 | 用实例和反例引出规则，再让用户把规则应用到另一个实例；必要时配对应图解 | 类比需说明适用边界，图不能只是装饰 |
| 元认知校准 | 在关键检验前问把握程度，作答后对照实际结果，选择下一步策略 | 自信不是成绩；不要求每道题填写问卷 |

证据来源：

- [Dunlosky 等，2013，学习技术综述](https://www.psychologicalscience.org/journals/pspi/1529100612453266/)：对练习测试和分散练习给予较高效用评价；自我解释与精细追问的适用证据更有条件。支持主干选择，不验证本 Skill 的完整效果。
- [Karpicke 与 Blunt，2011，检索练习实验](https://pubmed.ncbi.nlm.nih.gov/21252317/)：在研究任务中检索练习促进学习；不能外推为所有领域和所有任务下必然最优。
- [美国国家科学院，2018，How People Learn II 第五章](https://www.nationalacademies.org/read/24783/chapter/7)：知识基础、检索和知识应用的研究综合，为根据起点教学及检验应用提供依据。
- [IES，Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：支持结合样例与练习、连接具体与抽象表征等教学选择；不能将数学和科学中的证据无条件推广到全部领域。
- [IES，交错数学练习研究](https://ies.ed.gov/use-work/awards/efficacy-study-interleaved-mathematics-practice)：支持在相关任务间练习方法选择；其他领域需通过表现检验适用性。
- [美国国家科学院，2018，学习支持过程](https://www.nationalacademies.org/read/24783/chapter/6)：支持监控理解、利用反馈调整策略；本 Skill 的把握程度提问是具体实现选择。

## 关键词与概念地图

陌生领域可先选与目标相关的少量核心概念，按依赖和应用关系组织。每个概念给出日常解释、实例、易混概念和对应任务，随后让用户解释概念关系并实际应用。数量按目标决定，不凑 100 个词，不把熟悉术语当作掌握。

以上研究来源在构建时核实。以后引用新结论或教授动态领域事实时另行核实，不用名人标签替代证据。不把整个方案称为经过实验验证的教学产品。
