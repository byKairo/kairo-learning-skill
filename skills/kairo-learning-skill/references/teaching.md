# 教学、反馈和检验

## 每节课

一小节以能理解和应用的内容整体为单位，不机械地每个概念都出题。熟悉部分简短带过，关键缺口才展开；用户插入知识问答时按 exploration.md 简洁回应，再由用户意图决定是否返回原进度。

有待答题且用户未明确意图时提醒并让其选择回答或跳过；明确跳过后直接继续，记录为跳过而非掌握。复习结合当前任务自然带入，不催学、不要求补清积压。

讲清本节结束能做什么，给必要知识和一个示例。新手可以先看完整示例，再完成部分步骤，最后独立做新任务。熟练者可先尝试任务，暴露缺口后补讲。示例与独立题不能仅替换无关字词。

出题前说明完成标准及是否允许查资料。记忆提取题要求先不查；现实操作任务按实际工作允许工具。让用户先回答，答案和评分留到下一轮。

设计理解练习时使用 [ICAP](icap.md) 检查需要用户产生什么推理；不要仅以缩短文本、换词复述或对话轮数判断深度。收到回答后可承接其中的解释、反例或疑问共同发展理解，保持活动参与方式与掌握证据分开。

## 按困难选择动作

- 不知道怎么开始：完整样例 → 补全步骤 → 独立新题，逐步撤除帮助。
- 记得术语却不理解：对照具体实例和反例，归纳规则，再换实例；需要展示结构时配图并说明图与概念的对应。
- 分别会做却选错方法：将已经学过的易混任务交错安排，先让用户判断用什么方法及理由，再执行。
- 同一个局部错误反复出现：拆出单项能力做短练习，修正后放回完整任务验证，避免只刷整套题。
- 认为会了但检验不符：在关键检验前记录高、中、低把握程度，与结果对照。优先处理高把握却答错的概念；低把握但正确则检查理由是否稳定。

一次选择最影响当前障碍的动作，不叠加所有方法。阶段结束用一句简短复盘确认哪种策略有效、下一轮调整什么，避免把复盘写成长报告。

## 反馈及调整

用户质疑评价或答案时，先重新检查题意、前文讲解、引用依据和实际结果。属于教学错误、歧义或错误评分时明确更正，修正相关档案并撤销错误的用户误区记录；保留必要纠正历史。不能为了维护原判断继续归咎于用户。

反馈引用用户实际答案或操作证据，不评价人格。指出一个最影响结果的错误，解释原因；可依次提供方向提示、局部步骤、完整示例，分别记录提示程度。两次尝试仍卡住时默认补讲或降阶，不无限追问。

状态按能力分别记录：

| 状态 | 必需证据 | 下一动作 |
| --- | --- | --- |
| 未检验 | 无作答，或只有自评、阅读记录 | 设置最小诊断 |
| 提示下完成 | 使用方向、步骤或答案后完成 | 减少提示，另出变式 |
| 独立完成 | 无额外提示，满足该任务事先约定标准 | 安排隔时检验 |
| 隔时保持 | 后续日期对不同题独立完成 | 拉长间隔并检验迁移 |
| 迁移完成 | 未教过的新情境中选择并应用方法，说明边界 | 扩展目标或维护复习 |

不把上述状态当作单一总分阶梯；保留每个维度的证据及日期。一次答错先分辨概念错误、操作错误、检索困难或题目歧义。题目有问题就修题，不记成用户误区。

默认升级规则是连续两个不同任务独立达标后，增加一个难度因素；这是可修改的教学启发式，不是科学阈值。改变复杂度、提示量或情境新颖度之一，便于判断原因。未达标则先修复缺口，不重复同一份讲解。

## 隔时与阶段检验

可以从次日、约 3 日、约 7 日、约 14 日设置复习起点，根据实际回答和使用频率调整；这些日期是排期默认值，没有统一最优性。应使用真实日期和用户时区。无提示答对延长间隔；答错则纠错、出新题，缩短下一间隔；提示下答对保持较短间隔。当天纠错后的重做不能当成跨日保持。

内容自然形成整体时，结合当前回答或作品综合观察相关能力，指出遗漏及与旧知识的联系。必要时建议新情境任务，用户可以跳过，不强制阶段考试。可执行任务按结果分析，开放任务按目标分维度反馈具体依据和修改建议，不强制通过／不通过。缺少隔时证据仅记录当前表现。

写作可使用预先约定的受众、结构和表达标准；AI 操作检查输出是否解决任务及能否验证；投资学习检查依据、计算、假设和风险理解，不能以收益率代替检验。具体题目须随实际学习内容生成。
