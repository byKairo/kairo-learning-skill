# 学习档案字段模板

创建档案时将下列字段填写为实际信息；未知项写未提供或未检验。

## 当前摘要

- 领域与记录标识：
- 更新日期、时间及时区：
- 目标任务与使用场景：
- 评价维度、受众与表达偏好：
- 备课来源记录相对路径及适用版本：
- 完成标准及允许工具：
- 时间预算、目标日期：
- 已有基础（自述）：
- 诊断证据与前置缺口：
- 阶段路线及当前位置：
- 能力状态（按能力记录独立、保持、迁移证据）：
- 尚未解决的误区：
- 复习安排（能力、上次实际检验日期、结果、下次日期）：
- 当前待答题或下一步：
- 用户明确跳过的内容（不计为掌握）：
- 路线变更及依据：
- 最近会话记录相对路径：

## 每次会话记录

- 日期、时间及时区：
- 本次目标：
- 题目及预先约定标准：
- 实际回答摘要及证据来源：
- 是否允许资料、实际提示程度：
- 判定及依据：
- 关键检验的把握程度与实际结果差异（未询问则记未收集）：
- 误区、反馈、修正后新题表现：
- 状态变化及未检验部分：
- 下次复习日期及调整依据：
- 待答题与下一步：

## 无文件能力时的续学摘要

领域；目标；当前阶段；最近真实表现及提示程度；关键误区；到期复习；待答题；下一步。明确提醒用户保存这段文字以供后续恢复。
